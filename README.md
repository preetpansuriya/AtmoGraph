# ATMOGRAPH - Global Supply Chain Neural Digital Twin 🌐🚀

Yeh project ek **Autonomous Global Supply Chain Neural Digital Twin** hai. Isme Graph Neural Networks (GNN), 3D Interactive Globe, AIS Maritime Vessel tracking, Neo4j Cypher engine aur Mission Control Dashboard bundled hai.

---

## ⚡ VS Code me Exact Preview Output Run Karne Ka Tarika (Step-by-Step)

Jab aap is project ko zip download karke apne computer par extract karein, toh VS Code me exact preview paane ke liye yeh steps follow karein:

### Step 1: Project Folder ko VS Code me kholein
1. VS Code open karein.
2. `File` ➔ `Open Folder...` par click karein aur project ka main folder select karein.

### Step 2: Terminal kholein
- Keyboard Shortcut: `Ctrl + ~` (Windows/Linux) ya `Cmd + ~` (Mac)
- Ya fir top menu bar me **Terminal** ➔ **New Terminal** par click karein.

### Step 3: Dependencies install karein
Terminal me yeh command run karein:
```bash
npm install
```

### Step 4: App start karein
```bash
npm run dev
```

### Step 5: Browser me output dekhein
Terminal me aapko URL dikhega (e.g. `http://localhost:5173` ya `http://localhost:3000`).
- Browser me `http://localhost:5173` (ya terminal me diya gaya link) open karein.
- Aapko bilkul **wahi exact visual, live 3D globe, mission control KPIs, shockwave lab, aur 13 modules** milenge jo preview me dikh rahe hain!

## 🚀 Windows 1-Click Launch
Agar aap Windows use kar rahe hain:
- Project folder me maujood `run_local.bat` file par **Double Click** karein.
- Yeh automatically dependencies install karke browser me app open kar dega!

## 💡 Frontend Features (Built-in Zero-Config Engine)
- **Zero Python dependency needed for UI**: Saare PyTorch GNN calculations, AIS real-time simulations, aur Neo4j Cypher parsers frontend me high-performance JavaScript/WebGL engine me pre-configured hain.
- **Full Offline & Local Ready**: Kisi external server ya cloud API key ki mandatory zaroorat nahi hai.
