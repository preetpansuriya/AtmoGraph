# AtmoGraph NLP & LLM Model Registry

This directory contains configuration, weights, and fine-tuning metadata for the AtmoGraph NLP Engine.

## Capabilities
1. **Named Entity Recognition (NER)**:
   - Specialized dictionary and spaCy transformer pipeline matching global semiconductor fabrication nodes, Tier-1/2/3 assemblies, maritime ports, and straits.
2. **Disturbance & Severity Classifier**:
   - Zero-shot / DistilBERT text classification assessing geopolitical sanctions, meteorological anomalies, labor disputes, cyberattacks, and capacity stockouts.
3. **Gemini Pro Multi-Modal Reasoning**:
   - Multi-hop causal inference explaining GNN shockwaves in natural language.
